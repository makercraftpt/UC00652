O TinkerCAD é o ensaio geral antes da bancada física. Se funciona aqui, funciona no breadboard — as ligações são iguais.
Novidade desta aula: o timer do semáforo é o Arduino. Lê Q1 e Q0 e aguarda o tempo certo antes de avançar o clock.

Equações Simplificadas — AVANÇA = Clock

Quando o Arduino controla o clock, o MUX desaparece
3 / 9

Na Aula 8 (método MUX geral)

// Equação geral do método MUX:
D = (AVANÇA' · Atual) + (AVANÇA · Próximo)

D1 = AVANÇA'·Q1 + AVANÇA·Q0
D0 = AVANÇA'·Q0 + AVANÇA·(!Q1·!Q0)
Para o semáforo, Próximo_Q1 = Q0 (não é XOR!) e Próximo_Q0 = !Q1·!Q0. O padrão XOR só é válido para 4 estados em ciclo completo.

No TinkerCAD — AVANÇA = 1 sempre

// Se AVANÇA=1 sempre (clock = avança):
D = (0 · Atual) + (1 · Próximo) = Próximo

D1 = Q0 ← fio direto! sem portas
D0 = !Q1 · !Q0 ← 1 AND com !Q1,!Q0
O 74HC74 já tem as saídas !Q1 e !Q0 nos pinos complementados — não precisamos de NOT gates! Um AND entre !Q1 e !Q0 dá diretamente D0.
Resultado: o circuito fica com
▸ 1 fio: Q0 → D1
▸ 1 AND gate: !Q1 · !Q0 → D0
▸ Sem NOR, sem XOR, sem NOT extra
O Arduino controla QUANDO avança (timing por estado). O circuito controla PARA ONDE vai (equações de próximo estado).

Chips Necessários

74HC74 · 7408 · Arduino Uno — só 2 chips + Arduino
4 / 9

74HC74 — Dual D Flip-Flop (DIP-14)

!CLR e !PR são ativos a LOW. Ligar ao VCC (5V) para desativar — caso contrário o FF fica sempre em reset!

7408 — Quad 2-input AND (DIP-14)

// Só precisamos de 3 AND gates do 7408:
Gate 1: !Q0 AND !Q1 → D0 (pino 3)
Gate 2: !Q1 AND Q0 → LED_AMARELO
Gate 3: Q1 AND !Q0 → LED_VERMELHO

// D0 = LED_VERDE → mesmo fio, mesma saída!
LED_VERDE = D0 (saída do Gate 1)

Arduino Uno

Pin 13 → CLK1 (pino 3) e CLK2 (pino 11) do 74HC74
Pin 2 ← Q0 saída (pino 5 do 74HC74) [leitura]
Pin 3 ← Q1 saída (pino 9 do 74HC74) [leitura]
// GND do Arduino = GND do circuito (obrigatório!)
Total: 74HC74 + 7408 + Arduino. É o circuito mínimo funcional para o semáforo com timing automático!

74HC74 — Alimentação e Reset

1
Alimentação
Pin 14 → VCC (5V) · Pin 7 → GND. Sem isto nada funciona.
2
!CLR e !PR → VCC
Pins 1, 4, 10, 13 → VCC. São ativos a LOW — sem VCC o chip fica em reset permanente.
3
Clock
Pin 3 (CLK1) e Pin 11 (CLK2) → Arduino Pin 13. Os dois FFs partilham o mesmo clock.
4
D1 (entrada de dados FF1)
Pin 2 (D1) → Pin 5 (Q1). Fio direto — próximo estado de Q0 é sempre o Q0 atual!
5
D2 com AND gate
7408 Gate 1: entradas = Pin 6 (!Q0) e Pin 8 (!Q1) · saída → Pin 12 (D2). Isto é D0 = !Q1·!Q0.

7408 + LEDs + Arduino

6
LED VERDE
Saída do Gate 1 do 7408 (mesmo fio que D0) → resistência 220Ω → LED verde → GND.
7
LED AMARELO
7408 Gate 2: Pin 8 (!Q1) e Pin 5 (Q0) → resistência 220Ω → LED amarelo → GND.
8
LED VERMELHO
7408 Gate 3: Pin 9 (Q1) e Pin 6 (!Q0) → resistência 220Ω → LED vermelho → GND.
9
Arduino lê Q1, Q0
Arduino Pin 2 ← Pin 5 (Q0 saída) · Arduino Pin 3 ← Pin 9 (Q1 saída). GND do Arduino ao GND do circuito!

Arduino — Clock com Timing por Estado

Lê Q1 e Q0 · ajusta o delay · gera pulso de clock
7 / 9

Como funciona

  • Arduino lê Q1 (pin 3) e Q0 (pin 2) a cada ciclo
  • Determina o estado atual: VERDE, AMARELO ou VERMELHO
  • Aguarda o tempo correto para esse estado
  • Gera um pulso de clock: HIGH → delay(50ms) → LOW
  • O flanco ↑ do pulso dispara os FF-D → estado avança

Tempos sugeridos

EstadoQ₁Q₀Delay
VERDE003000 ms (3 s)
AMARELO01800 ms
VERMELHO103000 ms (3 s)
Muda os valores de delay e vê o efeito em tempo real no TinkerCAD — é a vantagem de usar Arduino como timer.

Sketch Arduino

// UC00652 · Aula 10 · Semáforo FSM // Arduino como clock com timing por estado const int CLK = 13; // saída de clock → 74HC74 const int Q0 = 2; // leitura Q0 (pino 5 do 74HC74) const int Q1 = 3; // leitura Q1 (pino 9 do 74HC74) void setup() { pinMode(CLK, OUTPUT); pinMode(Q0, INPUT); pinMode(Q1, INPUT); digitalWrite(CLK, LOW); } void loop() { int q1 = digitalRead(Q1); int q0 = digitalRead(Q0); // Tempo de espera por estado int tempo = 3000; if (q1==0 && q0==0) tempo = 3000; // VERDE if (q1==0 && q0==1) tempo = 800; // AMARELO if (q1==1 && q0==0) tempo = 3000; // VERMELHO delay(tempo); // Pulso de clock (flanco ↑ dispara o FF-D) digitalWrite(CLK, HIGH); delay(50); digitalWrite(CLK, LOW); }

Erros mais comuns no TinkerCAD

  • Todos os LEDs apagados — !CLR ou !PR não estão ligados ao VCC. O chip está em reset.
  • LEDs todos acesos ou a piscar errado — D1 não está ligado a Q0, ou D2 não recebe a saída do AND gate.
  • Só acende VERDE — GND do Arduino não está ligado ao GND do circuito. Os sinais de Q1/Q0 chegam com nível errado.
  • Clock demasiado rápido — aumenta o delay() no sketch. O TinkerCAD simula em tempo real.
  • Estado 11 aparece — circuito correto, é apenas o estado de arranque antes do reset. Adiciona !CLR ativo por 100ms no setup().
  • Tudo funciona — tira screenshot para o TP10!
Reset manual: liga o botão ao pino !CLR (pinos 1 e 13) do 74HC74 com resistência pull-up ao VCC. Ao premir → GND ativo → reset para VERDE (00).
