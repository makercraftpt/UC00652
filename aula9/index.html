O Sistema — Portão Automático

4 entradas · 4 estados · motor reversível · segurança obrigatória
3 / 9

Estados (2 FF-D)

EstadoQ₁Q₀MotorLED
FECHADO00Parado ↓Azul fixo
ABRINDO01Sobe ↑Verde pisca
ABERTO10Parado ↑Âmbar fixo
FECHANDO11Desce ↓Vermelho pisca

Entradas

BTNBotão do utilizador — abre se fechado, fecha se aberto
S_TOPSensor fim de curso superior — portão totalmente aberto
S_BOTSensor fim de curso inferior — portão totalmente fechado
S_SEGSensor de segurança — obstáculo detetado durante fecho

Ciclo normal

  • Portão em FECHADO — utilizador prime BTN → motor arranca, estado → ABRINDO
  • Motor sobe até S_TOP=1 → para automáticamente, estado → ABERTO
  • Utilizador prime BTN novamente → motor desce, estado → FECHANDO
  • Motor desce até S_BOT=1 → para, estado → FECHADO

Transição de emergência

S_SEG=1 durante FECHANDO — obstáculo detetado (pessoa, veículo, animal).
Motor inverte imediatamente: estado → ABRINDO.
Sem novos estados. Sem novo FF-D. Só uma equação diferente para D₀.
Nos portões industriais, S_SEG é normalmente uma barreira de infravermelhos ou sensor de pressão no bordo do portão. Requisito legal em instalações com passagem de pessoas.

Moore · 4 estados · 2 FF-D · seta de emergência a vermelho

Legenda

  • Setas verdes — transição normal (BTN ou sensor de fim de curso)
  • Setas azuis — retorno ao estado base (FECHADO)
  • Setas a tracejado — self-loops (estado mantém-se)
  • Seta vermelha a tracejado grosso — transição de emergência S_SEG: FECHANDO → ABRINDO

Observações chave

4 estados → 2 FF-D (Q₁Q₀). O estado 11 é válido (FECHANDO) — diferente do semáforo onde 11 era don't care.
A seta de emergência é a novidade: de FECHANDO podem ir para 2 estados diferentes consoante a entrada (S_BOT → FECHADO, S_SEG → ABRINDO). Isto muda D₀_next mas não D₁_next.

Leitura das colunas — quando AVANÇA=1

D₁_next: 0, 1, 1, 0, 0
→ 00→0, 01→1, 10→1, 11→0, 11(seg)→0
= XOR(Q₁, Q₀) // padrão em todos os casos!
D₀_next: 1, 0, 1, 0, 1
→ normalmente inverte Q₀ (1,0,1,0)
→ exceto FECHANDO+S_SEG: fica a 1
= Q₀' + (Q₁·Q₀·S_SEG)

AVANÇA por estado

// BTN ativo quando Q₀=0 (FECHADO e ABERTO)
// S_TOP só em ABRINDO (Q₁'·Q₀)
// S_BOT ou S_SEG só em FECHANDO (Q₁·Q₀)
AVANÇA = BTN·Q₀' + S_TOP·Q₁'·Q₀ + (S_BOT+S_SEG)·Q₁·Q₀
S_SEG só afeta D₀ — e apenas no estado FECHANDO. D₁ é XOR(Q₁,Q₀) independentemente da emergência.

Equações Finais — Método MUX

D = (AVANÇA' · Atual) + (AVANÇA · Próximo)
6 / 9

Os dois MUX

MUX 2:1 → D₁
A₀ = Q₁ (fica)
A₁ = XOR(Q₁,Q₀) (avança)
Sel = AVANÇA
D₁ = AVANÇA'·Q₁ + AVANÇA·XOR(Q₁,Q₀)
MUX 2:1 → D₀
A₀ = Q₀ (fica)
A₁ = Q₀' + Q₁·Q₀·S_SEG (avança)
Sel = AVANÇA
D₀ = AVANÇA'·Q₀ + AVANÇA·(Q₀'+Q₁·Q₀·S_SEG)
O extra do sensor de segurança é apenas um termo AND a mais no ramo A₁ do MUX D₀: Q₁·Q₀·S_SEG — é a deteção do estado FECHANDO com obstáculo.

Componentes necessários no LogiSim

// AVANÇA
NOT(Q₀) → AND com BTN → parte A
NOT(Q₁), AND com Q₀, AND com S_TOP → parte B
OR(S_BOT,S_SEG), AND com Q₁, AND com Q₀ → parte C
OR(A, B, C) → AVANÇA

// D₁
XOR(Q₁,Q₀) → MUX A₁ · Q₁ → MUX A₀ · Sel=AVANÇA → D₁

// D₀ (bloco de emergência)
NOT(Q₀) → OR com (AND Q₁,Q₀,S_SEG) → MUX A₁
Q₀ → MUX A₀ · Sel=AVANÇA → D₀
Componentes: 2 FF-D · 2 MUX 2:1 · 1 XOR · 3 NOT · 5 AND · 3 OR · 4 LEDs saída
Saídas Moore: LED_F=Q₁'·Q₀' · LED_A=Q₁'·Q₀ · LED_AB=Q₁·Q₀' · LED_FE=Q₁·Q₀

Ligação à Automação Industrial

Do LogiSim ao PLC · segurança obrigatória em instalações reais
8 / 9

Do FSM ao GRAFCET (IEC 61131-3)

// PLC Siemens S7 — linguagem SFC/GRAFCET
ETAPA FECHANDO:
  TRANSIÇÃO → FECHADO: S_BOT
  TRANSIÇÃO → ABRINDO: S_SEG // emergência

// Em Ladder (LD):
|---[S_BOT]---[/FECHANDO_ATIVO]---( SET FECHADO )
|---[S_SEG]---[/FECHANDO_ATIVO]---( SET ABRINDO )
A transição de emergência S_SEG tem prioridade sobre S_BOT em PLCs reais — é tratada como interrupção ou transição de maior prioridade no SFC.

Normas de segurança

  • EN 12453 — requisitos de força e segurança para portões motorizados
  • ISO 13849 — nível de desempenho (PL) para funções de segurança
  • S_SEG em instalações reais = categoria SIL 2 (sensor redundante)
  • O FSM que modelaram hoje é a base do controlador de segurança
