Método MUX — FSM com Flip-Flops D

  1. Definir os estados — codificar em binário (Q1 Q0). Para n estados precisamos de k FF-D onde 2k ≥ n.
    2 estados → 1 FF  |  4 estados → 2 FF  |  8 estados → 3 FF
  2. Definir AVANÇA — condição booleana que faz a FSM avançar de estado (sensores, botões, timer…)
  3. Preencher a tabela de transições — para cada estado: condição de AVANÇA, estado seguinte (Q1_next, Q0_next)
  4. Calcular D com a fórmula MUX
  5. Implementar saídas Moore — dependem apenas do estado (Q1, Q0), nunca das entradas
D  =  AVANÇA' · Qactual  +  AVANÇA · Qnext
Notação:  AVANÇA' = !(AVANÇA) — complemento (NOT) de AVANÇA
AVANÇA é o sinal que agrupa todas as condições (sensores, botões, timer…) que fazem a FSM avançar.
 · AVANÇA = 0 → estado mantém-se  (self-loop: D = Qactual)
 · AVANÇA = 1 → estado avança      (D = Qnext)

Álgebra Booleana — Identidades úteis

A · 1 = A
A + 0 = A
A · 0 = 0
A + 1 = 1
A · !A = 0
A + !A = 1
A + A·B = A   (absorção)
A·(A+B) = A  (absorção)
!(A·B) = !A + !B  (De Morgan)
!(A+B) = !A · !B  (De Morgan)
A⊕B = A·!B + !A·B  (XOR)
A⊕0 = A  |  A⊕1 = !A
